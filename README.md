# Wedding Memories Cloud

A private cloud-based platform for storing and viewing wedding photos and videos.

## Current Stage

- Python Flask application
- Local development environment
- Git version control

## Planned AWS Architecture

- EC2 / ECS for application compute
- S3 for photos and videos
- RDS for metadata
- ALB for traffic distribution
- CloudWatch for monitoring
- Terraform for infrastructure
- CI/CD for automated deployment
